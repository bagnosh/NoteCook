COMPLETED THIS SESSION:
------------------------
Recipe detail screen visual overhaul:
- Section titles (Ingredients / Tools / Steps) now sit on marker-highlight
  PNG strokes (peach / mint / purple), sized to hug the actual measured
  text via onLayout rather than guessed padding
- Ingredients / Tools / Steps each wrapped in a semi-transparent
  "SectionCard" (near-opaque cream, slightly brighter than the paper) to
  separate content from the paper texture's ruled lines
- Tools section switched from plain text rows to checkboxes, matching
  Ingredients / Steps
- Checkbox "checked" color changed from mint to #D2915A (border + checkmark)
  everywhere in the recipe screen
- Recipe photo gets a decorative frame_empty_round.png border, tinted cream
  (#f8f1e7); photo container made square to match the frame's native aspect
- Notes section redesigned: dropped an earlier stretched-PNG frame attempt
  (looked distorted/"smushed"); now a plain rounded card matching
  SectionCard's shape, solid #D2915A background, peach highlight-stroke
  title, dark #6F4E37 text for contrast
- Paper background simplified to a single paper.png image (dropped an
  earlier 3-slice tiling approach that didn't render reliably) as a fixed,
  non-scrolling backdrop; repositioned/zoomed via precise pixel
  measurement so the ruled margin line sits at ~1/5 of screen width
  instead of ~1/3

Bug fixes found mid-session:
- Fixed a real regression: an unstable inline style array on the highlight
  title's text caused the highlight banner images to get stuck at
  opacity 0 (fade-in transition never settled). Fixed with useMemo +
  a guarded onLayout state update
- Renamed 7 uppercase .PNG asset files to lowercase .png for
  cross-platform safety

Favourites feature (new):
- Recipe detail's star toggle now actually persists to AsyncStorage via
  updateRecipe() -- previously it only changed local state and reverted
  every time you left the screen
- Added a "Favourites only" toggle to the Search tab (combinable with
  name/ingredient filters), with a star badge on matching result cards
- Added a favourites-only toggle (star icon) to the Category Detail
  screen header
- Added a "Favourites" toggle to the top-level Categories tab (next to
  the heading), filtering categories to only those containing favourited
  recipes, with the badge count switching to reflect favourites
- Home screen recipe cards now show a star badge for favourited recipes
